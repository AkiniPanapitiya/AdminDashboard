# Inka Web - Admin Dashboard

An enterprise-grade, responsive Admin Dashboard built for managing product inventories, dynamic pricing models, and commission-based staff salary tracking in real-time.

## 🚀 Key Features

* **Product CRUD**: Create, read, update, and delete product listings effortlessly.
* **Inventory Management**: Real-time stock level tracking and automated reorder alerts.
* **Dynamic Pricing**: Flexible pricing management based on market trends and custom business rules.
* **Commission & Salary Tracking**: Automated salary calculations integrated with commission metrics.

## 🛠️ Tech Stack

* **Frontend**: React.js / HTML5, CSS3, JavaScript (ES6+)
* **Version Control**: Git & GitHub (Agile SDLC Branching Strategy)
* **Project Management**: Jira
